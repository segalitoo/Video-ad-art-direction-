## Hooks (on-screen, first 2 seconds, max words per the lock)
Draft at least five per angle, one per mechanic, then keep three. Only the hook changes between
variants; everything after it stays the same, so the test reads the hook alone.

| Mechanic | What it does | Shape |
|---|---|---|
| confession | the viewer's own mistake, admitted | "I was the one who..." |
| contrarian | flips what the category says | "Everyone says X. It's Y." |
| curiosity | opens a gap the ad closes | "Nobody told me this about..." |
| result | the outcome first, the how later | "Paid in 1 day, not 5." |
| challenge | calls out a habit | "Still doing X? Stop." |
| stat | one number that surprises (proof block only) | "93% ..." |
| question | a question the buyer is already asking | "Why does X keep...?" |
| visual | the first frame does the work, few or no words | "Watch this invoice cross the world." |

Rules (checked): under 12 words; no two hooks start with the same word; three or more hooks
cover at least three mechanics; no word from `guardrails.never_say`; numbers only from `proof`.

*native* (first person, casual, reads like a real post).
